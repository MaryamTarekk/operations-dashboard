# ⚡ OpsPulse Enterprise — Operations Dashboard

A modern operations dashboard built with **React 19, TypeScript, Vite, TanStack Query v5, and Tailwind CSS v4**.

## ✨ Features

- **Smart Search:** Debounced search with URL synchronization.
- **Optimistic Updates:** Instant status changes with automatic rollback on failure.
- **Request Management:** Edit request details with unsaved changes protection.
- **Dark & Light Mode:** Theme switching with localStorage persistence.
- **Auto Refresh:** Background data updates every 30 seconds.
- **Responsive UI:** Modern design with a sticky, collapsible sidebar.
- **Automated Tests:** Tests maintained separately from the main UI.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` and click **Launch Dashboard**.
